Aufgabe 1

Mit Hilfe einer Java-Funktion soll die Fakultät einer natürlichen Zahl n bestimmt werden. Die Fakultät bildet das Produkt aller natürlichen Zahlen bis zum Parameter n. Beispiele:

  • fakultaet(3) ist 1*2*3 = 6
  • fakultaet(4) ist 1*2*3*4 = 24
  • fakultaet(0) ist per Definition 1
Korrigieren Sie bitte alle Fehler in der gegebenen Funktion (inkl. fehleranfälliger Code-Teile) und sorgen Sie dafür,dass das gegebene Programm funktioniert und korrekte Werte bestimmt.



Aufgabe 2

Erstellen Sie eine Funktion min, die als Parameter ein double-Array erhält. Die min-Funktion soll den minimalen Wert des Arrays zurückgeben.



Aufgabe 3

Entwerfen Sie eine eigene Klasse Rechteck, die als Attribute die Breite, Höhe sowie die Ursprungskoordinaten x und y bekommt (alle vom Typ double). Beabeiten Sie die folgenden Teilaufgaben:

  • Definieren Sie einen Konstruktor, der alle Attribute korrekt initialisiert.
  • Definieren Sie einen Konstruktor, der keine Parameter erhält. Initialisieren Sie alle Attribute sinnvoll.
  • Erstellen Sie eine Methode scale, die das gesamte Rechteck entsprechend eines übergebenen double-Parameters factor skaliert (Größe anpassen).
  • Erstellen Sie eine Methode draw, die das Rechteck mit Hilfe der in JOE eingebauteten Rectangle-Klasse darstellt.
