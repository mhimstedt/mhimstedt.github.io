Aufgabe 1

Mit Hilfe einer Java-Funktion soll die Quersumme einer ganzen Zahl bestimmt werden. Die Quersumme wird bestimmt, indem die einzelnen Ziffern (Stellen) einer Zahl addiert werden, z.B. quersumme(123) soll 6 ergeben, quersumme(372) soll 12 ergeben. Die Funktion ist bereits implementiert, enthält aber Fehler. Korrigieren Sie bitte alle Fehler in der gegebenen Funktion (inkl. fehleranfälliger Code-Teile) und sorgen Sie dafür, dass das gegebene Programm funktioniert.



Aufgabe 2

Erstellen Sie eine Klasse Point3D, die einen Punkt (x,y,z) im 3D-Raum beschreiben und von der gegebene Point-Klasse erben soll. Passen Sie Methoden der Point-Klasse in geeigneter Weise für Point3D an. Nutzen Sie für die Klasse Point3D bitte die Datei Point3D.java.

Aufgabe 3

Implementieren Sie bitte eine Funktion sechsWuerfeln, die das Spielen eines Würfels so oft wiederholen soll, bis eine 6 gewürfelt wurde. Mit dem Parameter maxVersuche soll eine maximale Anzahl von Wiederholungen vorgegeben werden. Wird diese erreicht, so soll das Würfeln beendet werden, auch wenn noch keine 6 gewürfelt wurde. Geben Sie bitte die Anzahl Versuche zurück. Diese nutzt das Programm, um herauszufinden, ob eine 6 erfolgreich gewürfelt wurde oder nicht. Wenn die maximale Anzahl an Versuchen (maxVersuche) erreicht wurde, gibt das Programm eine Rückmeldung, dass keine 6 gewüfelt wurde (siehe Programm).
