Aufgabe 1 (20 Punkte)

Mit Hilfe einer Java-Funktion sollen ganzzahlige Noten (1, ... , 5; engl. grade) in Textausdrücke (sehr gut, ... , ungenügend) konvertiert (umgewandelt) werden. Dafür wird Ihnen bereits Programm-Code vorgegeben, den Sie bitte korrigieren bzw. erweitern, sodass dieser eine Konvertierung entsprechend der Tabellenwerte ermöglicht und dabei die genannten Anforderungen erfüllt. Zum Testen können Sie den Programm-Code von Main.java ausführen. Bitte verändern Sie den Code in Main.java nicht.

Note Ausdruck
1 sehr gut
2 gut
3 befriedigend
4 ausreichend
5 ungenügend

Anforderungen:

  • Es sind nur ganzzahlige Noten als Eingabe möglich.
  • Es sind nur die in der Tabelle angegebenen Noten zu konvertieren.
  • Für ungültige Eingaben (Noten) soll "Keine Bewertung" zurückgegeben werden.
  • Rückgabetyp soll String sein.
  • Halten Sie die in der Vorlesung eingeführten Konventionen zu Variablen- und Funktionsnamen, Einrückungen und Blockbildung ({}) ein.
  • Der switch-Konstrukt soll beibehalten werden.



Aufgabe 2 (20 Punkte)

Erstellen Sie eine Funktion range, die als Parameter ein double-Array x bekommt und für die übergebenen Werte die Spannweite bestimmt. Die Spannweite range(x) ergibt sich als Differenz aus dem Maximum xmax und dem Minimum xmin aller Array-Werte x:
range(x) = xmax - xmin

Beispiel: x = [1.3, -2.4, 5.6, 10.9, 20.1, -17.4] range(x) = 37.5



Aufgabe 3 (10 Punkte)

In dieser Aufgabe soll ein Programm implementiert werden, dass bestimmen kann, ob 2D-Punkte innerhalb oder außerhalb eines vorgegebenen Fensters (Window) liegen. Sie haben dafür die aus dem Praktikum bekannten Klassen Point und PointRGB sowie eine Methode randomPoints bereits gegeben. Entwickeln Sie nun einen Punktfilter (window filter). Bearbeiten Sie dazu bitte die folgenden Teilaufgaben.

Teilaufgaben:

  1. WindowFilter-Klasse: Implementieren Sie in WindowFilter.java eine Klasse WindowFilter, die von der Klasse Rectangle erbt. Der Konstruktor von WindowFilter soll minX, maxX, minY und maxY übergeben bekommen. Beachten Sie, dass die Klasse Rectangle aber etwas anders initialisiert werden muss (siehe Cheat Sheet).
  2. Fenster anzeigen: Sorgen Sie dafür, dass das Fenster (Rectangle) des WindowFilter angezeigt wird. Nutzen Sie die Methoden setFillColor sowie setBorderColor, um den Hintergrund schwarz und die Randlinien weiß zu zeichnen. Ggf. ist auch der Aufruf von setVisible notwendig.
  3. Punkte filtern: Implementieren Sie in der Klasse WindowFilter die Methode filter, welche ein Point-Array als Parameter bekommt und ein PointRGB- Array zurückgibt. Prüfen Sie hier, ob die übergebenen Punkte innerhalb oder außerhalb des festgelegten Fensters liegen. Sie können dafür bspw. die Attribute von Rectangle (Höhe, Breite, Mittelpunkt) oder alternativ die Rectangle-Methode containsPoint(double x, double y) verwenden. Punkte, die innerhalb des Fensters liegen, sollen eine blaue Farbe bekommen. Punkte außerhalb des Fensters sollen eine rote Farbe erhalten (siehe PointRGB).
  4. Punkte zeichnen: Implementieren Sie in der Klasse WindowFilter die Methode draw, die alle übergebenen Punkte (PointRGB-Array) zeichnen soll. Hinweis: Die Klasse PointRGB hat bereits eine Methode draw, die Sie hierfür verwenden können.

In der Datei Main.java sehen Sie einen Beispielaufruf für das gesamte Programm, das dieselbe Ausgabe erzeugt, wie es in der folgenden Abbildung dargestellt ist, sofern alles korrekt implementiert ist.
