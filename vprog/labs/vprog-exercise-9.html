Praktikum 9: Suchen und Sortieren

In diesem Praktikum wollen wir den Einsatz von Such- und Sortierverfahren praktisch in Java üben.

🚀 Lernziele

Sie können:

  • geeignete Suchverfahren auswählen
  • die Laufzeit von Algorithmen messen
  • gezielt entscheiden, wann Sortierung von Daten sinnvoll ist

🤔 Vorbereitung

Arbeiten Sie bitte noch einmal sorgfältig die Vorlesungsmaterialien Suchen und Sortieren durch.

Implementieren Sie dann bitte vor Ihrem Praktikumstermin eine Funktion generateRandomNumbers zur Erzeugung von ganzzahligen Zufallszahlen.

Anforderungen:

  • Eingabedaten: Sie erhalten die Anzahl Zufallszahlen, die erzeugt werden sollen (int) sowie die obere Grenze (max. Zahl, die zurückgegeben werden soll, int).
  • Rückgabe: Ihre Funktion soll Zufallszahlen als ArrayList zurückgeben.

📝 Pflichtaufgaben (1 Bonuspunkt)

1 - Lineare Suche für ganze Zahlen

Implementieren Sie bitte eine lineare Suche für ganze Zahlen. Orientieren Sie sich gern an dem Beispiel aus der Vorlesung (siehe Lernraum: Beispiele). Beachten Sie bitte die folgenden Anforderungen.

Anforderungen:

  • Eingabedaten: Sie erhalten eine ArrayList mit ganzen Zahlen sowie eine Suchelement (Query, ebenfalls ganzzahlig).
  • Rückgabe: Ihre lineare Suche soll eine ArrayList mit den Positionen, an denen das Suchelement (Query) gefunden wurde, zurückgeben.

2 - Binäre Suche für ganze Zahlen

In dieser Aufgabe soll nun eine binäre Suche implementiert werden. Den Algorithmus dazu finden Sie in der Vorlesung zum Thema Suchen. Beachten Sie die folgenden Anforderungen für Ihre Implementierung.

Anforderungen:

  • Zufallszahlen: Erzeugen Sie Zufallszahlen mit Ihrer Implementierung aus der Vorbereitung.
  • Sortieren: Die binäre Suche setzt voraus, dass Ihre Daten vorsortiert sind. Das können Sie in Java für bspw. eine ArrayList list durch den Aufruf Collections.sort(list) erreichen.
  • Eingabedaten für Funktion: Sie erhalten eine ArrayList mit ganzen Zahlen sowie eine Suchelement (Query, ebenfalls ganzzahlig).
  • Rückgabe: Ihre binäre Suche soll eine Position zurückgeben, an der das Element gefunden wurde. Das reicht bei diesem Verfahren aus, da die Daten ja vorsortiert vorliegen (müssen) und Kopien (=gleiche Zahlen) ohnehin direkt nachfolgend in der Liste eingeordnet sind.
  • Testen: Testen Sie Ihre Implementierung bitte mit Ihren bereits erzeugten Zufallszahlen.

3 - Laufzeitmessung zum Vergleich der Verfahren ⏱️

Jetzt wird es spannend, denn wir wollen die beiden Implementierungen nun vergleichen. Kopieren Sie bitte Ihre Implementierungen für die lineare und binäre Suche in das nachfolgende IDE-Fenster und führen Sie eine Laufzeitanalyse durch. Sie haben dafür bereits einen Beispielblock gegeben, den Sie für weitere Messungen kopieren und (leicht angepasst) wiederverwenden können. Ändern Sie bitte nicht die Geschwindigkeit Ihrer IDE (Schieberegler), da das die Messung beeinflusst.

Testen Sie Implementierung bitte mit den folgenden Listengrößen: 10, 100, 500

Was stellen Sie fest? War dieses Ergebnis erwartbar? Warum bzw. warum nicht? (Bitte mit den Lehrbeauftragten im Praktikum diskutieren.)
