Praktikum 13: Netzwerkprogrammierung

In diesem Praktikum wollen wir verteilte Anwendungen entwickeln, die über Netzwerk miteinander kommunizieren können. Dafür verwenden wir Java unter Nutzung der IDE IntelliJ IDEA.
Konkret: Wir wollen unsere Kontaktliste (AddressBook) nun von einem Server laden. Das Experiment wird auf unserem lokalen PC getestet (Client und Server auf gleichem Rechner). Grundsätzlich kann diese Anwendung aber auch über das Netzwerk genutzt werden. Das setzt allerdings entsprechende Einstellungen der Firewall voraus.

🚀 Lernziele

Sie können:

  • verteilte Anwendungen in Java entwickeln
  • sicher mit Sockets in Java umgehen
  • Objekte serialisieren

Bringen Sie bitte Ihre Implementierungen der Klassen Contact, AddressBook und Address wieder mit.
