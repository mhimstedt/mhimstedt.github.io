Geometrische Grundformen und Wiederholungen

Ziel: Darstellung von Horizont, Berge und Mond

In diesem Praktikum wollen wir zunächst im Canvas einen Horizont darstellen. Diese Darstellung wird dann um einfache (wiederholende) Bergstrukturen sowie einen Mond erweitert. Das Ergebnis soll dann in etwa wie die folgende Grafik aussehen:

Vorbereitung

Die folgenden Aufgaben setzen voraus, dass Sie die zugehörigen Vorlesungmaterialien vollständig durchgearbeitet haben: Vorlesung 2

Aufgaben

Die folgenden Teilaufgaben leiten Sie sukzessive zum Ziel. Ihre Lösungen können Sie in den entsprechenden Code-Fenstern der Online-IDE direkt implementieren und live mit dem eingebauteten (verschiebbaren) Canvas testen.

  1. Nachthimmel Legen Sie einen schwarzen Hintergrund an, der zunächst den gesamten Canvas bedeckt.
  2. Weißer Kreis Erstellen Sie nun einen weißen Kreis zentriert auf dem Canvas. Testen Sie Ihre Implementierung. Was fällt Ihnen auf, wenn Sie die Canvasgröße verändern?
  3. Normalisierung Initialisieren Sie in der main-Funktion die Variable uv so, dass jeder Pixel eine positionsabhängige 2D-Koordinate im Bereich [-1, 1] erhält. Dazu müssen Sie den Wertebereich von [0, 1] auf [-1, 1] transformieren. Korrigieren Sie anschließend das Seitenverhältnis, damit bspw. Kreise auf nicht-quadratischen Auflösungen nicht verzerrt dargestellt werden. Testen Sie nun erneut Ihre Funktion mit einem einfachen Kreis, der durch Veränderung der Canvas-Größe nun nicht mehr verzerrt dargestellt werden sollte (keine Ellipse!).
    Hinweis: Sie können die Uniform-Variable u_resolution mit einer Koordinate multiplizieren, um das Seitenverhältnis zu korrigieren.
  4. Berge (Hintergrund, monochrom) Als nächstes wollen wir Berge erstellen. Wir beginnen erstmal mit den Bergen im Hintergrund (siehe: Bild am Anfang). Modellieren Sie die Berge durch Nutzung der Sinus-Funktion (sin), die als Parameter die x-Koordinate erhalten soll (siehe auch: Vorlesungsbeispiel). Gewichten Sie den Parameter (uv.x) mit einem konstanten Faktor, der die Frequenz der Bergdarstellung bestimmt. Den Rückgabewert der Sinusfunktion gewichten Sie bitte nochmal mit einem kleinen Wert (z.B. ~ 0.2), um die Amplitude zu bestimmen. Wenn Sie dann noch einen konstanten Offset hinzu addieren, können Sie den Ursprung der Berge später verschieben.
    Mit Hilfe der step-Funktion bestimmen Sie bitte den Farbwert durch Angabe der ux.y-Koordinaten sowie der vorher bestimmten Werte (Sinusfunktion), analog zum Vorlesungsbeispiel.
    Wenn Sie auf die numerischen float-Parameter innerhalb der Klammern klicken, können Sie die Variablen interaktiv verändern. Spielen Sie ein bisschen damit herum und beobachten Sie, was sich an der Ausgabe verändert.
  5. Berge (Hintergrund, versch. Farben) Wir wollen nun unsere erstellten (monochromen) Berge mit Farben versehen. Dazu können wir die Funktion mix verwenden. Schauen Sie sich diese zunächst genauer an. Die ersten beiden Parameter bestimmen den Wertebereich (hier: Farbe), auf den abgebildet (interpoliert) werden soll. Als untere Grenze können Sie Ihren Nachthimmelhintergrund verwenden. Für die oberen Grenzen können Sie einen vec3-Vektor mit RGB-Grenzen (z.B. vec3(0.2)) übergeben. Der letzte Parameter ist unsere aktuelle (monochrome) Darstellung (der Berge). Visualisieren Sie die Ergebnisse und experimentieren Sie wieder mit den Parameterwerten.
  6. Berge (Vordergrund) Versuchen Sie nun eine weitere Berggruppe im Vordergrund zu erzeugen, die etwas flacher ist (siehe Abb. oben). Sie können dazu die Vorgehensweise aus der vorhergehenden Aufgabe wiederholen, aber unterschiedliche Parameter verwenden.
    Tipp: Wenn Sie den Parameter der Sinusfunktion (x-Koordinate) mit einem konstanten Offset versehen (+ offset), können Sie die Bergformation komplett verschieben.
  7. Mond (als Kreis) Legen Sie zunächst einen hellgelben Kreis an, der auf dem Nachthimmel überhalb der Berge dargestellt wird.
  8. Mond mit Oberflächenstruktur Versuchen Sie nun mithilfe Ihrer rand-Funktion aus dem vorhergehenden Praktikum eine Oberflächenstruktur durch ein pseudo-zufälliges Rauschen zu erzeugen. Hinweis: Sollten Sie die rand-Funktion nicht zur Verfügung haben, sprechen Sie gern die Praktikumsbetreuer:innen an.
  9. Mondphasen (statisch) Stellen Sie unterschiedliche Mondphasen, bspw. durch Überblenden mit einem dunklen Kreis (Farbe wie Nachthimmel), dar. Stellen Sie die Mondphase zunächst einmal konstant ein. Versuchen Sie aber schon eine variable Anpassung über einen Parameter entlang der x-Achse zu ermöglichen.
  10. Mondphasen (wechselnd) Verwenden Sie nun die Uniform-Varible u_time und eine Sinus-Funktion, um eine zeitliche Verschiebung der Mondphasen zu ermöglichen.
    Hinweis: Sie können das erreichen, indem Sie den Überblend-Kreis einfach entlang der x-Achse wandern lassen.
