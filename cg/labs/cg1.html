Einführung in Shader-Programmierung

Ziel: Darstellung eines Sternenhimmels

Vorbereitung

Die folgenden Aufgaben setzen voraus, dass Sie die zugehörigen Vorbereitungsaufgaben vollständig abgeschlossen haben: Materialien zur Vorbereitung

Aufgaben

In diesem Praktikum wollen wir einen Sternenhimmel als Fragment-Shader implementieren. Dieser soll aus vielen, kleinen hellen Punkten (=weiß) auf schwarzem Untergrund bestehen. Außerdem wollen wir einen Szintillationseffekt ("Flackern" von Sternen) simulieren.

Die folgenden Teilaufgaben leiten Sie sukzessive zum Ziel. Ihre Lösungen können Sie in den entsprechenden Code-Fenstern der Online-IDE direkt implementieren und live mit dem eingebauteten (verschiebbaren) Canvas testen.

  1. Starte zunächst mit einem einfachen monochromen Verlauf. Dazu können Sie die Variable uv (vom Typ vec2) anlegen. Lesen Sie dann die x- und y-Koordinaten von gl_FragCoord ein. Normalisieren Sie diesen auf den Wertebereich [0,1] unter Zuhilfenahme der Uniform-Variablen u_resolution (auch x und y). Sie können das direkt als Vektoroperationen (Einzeiler) implementieren.
  2. Der Verlauf ist aktuell entlang der x-Achse sichtbar. Passen Sie den Code so an, dass der Verlauf entlang der y-Achse dargestellt wird.
  3. Erzeugen Sie nun einen diagonalen Verlauf, indem Sie die x- und y-Komponenten kombinieren v = x + y. Verwenden Sie den Vektor v als Farbkomponente.
  4. Verwenden Sie nun anstelle der Summe aus x + y für v das Skalarprodukt mittels der Funktion dot. Als Parameter sollte der gesamte Vektor uv sowie ein zwei vec2-Vektor übergeben werden. Nutzen Sie hierfür einfach zwei float-Zahlen.
  5. Wenn Sie auf die numerischen float-Parameter innerhalb der Klammern klicken, können Sie die Variablen interaktiv verändern. Spielen Sie ein bisschen damit herum und beobachten Sie, was sich an der Ausgabe verändert.
  6. Bisher besteht unsere Farbwertberechnung nur als lineare Operationen. Das wollen wir jetzt ändern. Um ein wenig Nichtlinearität in Spiel zu bringen, können wir eine trigonometrische Funktion (z.B. sin) verwenden. Passen Sie die Berechnung von v dementsprechend an.
  7. Echte Zufallswerte haben wir bisher noch nicht erzeugt. Wir werden nun etwas Chaos reinbringen. Multiplizieren Sie dazu die Variable v mit einem sehr hohen Wert (>10.000). Für eine korrekte Farbdarstellung brauchen wir natürlich Werte im Bereich [0,1]. Normalisieren Sie v entsprechend mittels der Funktion fract (abgeleitet von engl. fractional). Letztere übernimmt nur den Nachkommateil einer Gleitkommazahl (z.B. fract(4.2) -> 0.2). Schauen Sie sich das Ergebnis an. Was stellen Sie fest?
  8. Lagern Sie den Teil zur Bestimmung von v = ... nun in eine eigene Funktion rand (Rückgabetyp: float, Parametertyp: vec2) aus. Integrieren Sie die Funktion in ihrer main und stellen Sie das gleiche Ergebnis wie in der vorhergehenden Teilaufgabe her.
  9. Sie können jetzt Funktion rand nutzen, um Sterne zu zeichnen. Multiplizieren Sie dazu uv mit bspw. 100.0 und runden Sie den Wert mittels floor bzw. ceil. Wir sollten nun ein wunderschönes Zufallsmuster sehen, die aber leider noch keinen Anscheinen von Sternen wecken. Haben Sie Geduld!
  10. Wir haben nun ein sehr feines Muster erzeugt. Wir müssen dieses große Muster "nur" noch etwas ausdünnen. Das können wir mit Hilfe der Funktion step(t, x) erreichen. Diese fungiert als Schwellwertfunktion. Ist der übergebene Wert x < t, so gibt dieser 0 zurück, anderenfalls 1. Wählen Sie als Schwellwert einen Parameter nahe 1 (z.B. 0.99). Probieren Sie es aus und lassen Sie sichvom Ergebnis (hoffentlich) überraschen!
  11. Zuguterletzt wollen wir noch den o.g. **Szintillationseffekt** integrieren. Dazu können wir in gl_FragColor die Uniform-Variable u_time in Kombination mit einer Funktion, die unsere Werte in regelmäßigen (wiederkehrenden!) Abständen anpasst. Machen Sie sich Gedanken, wie das funktionieren könnte. Tipp: Diese mathematische Funktion haben wir heute schon benutzt. Die Zeit kann einfach Parameter dieser Funktion werden.
