1 - Die Student-Klasse

In dieser Aufgabe soll eine neue Klasse Student angelegt werden. Studierende können aus Sicht der Informatik als eine Spezialisierung von Personen modelliert werden. Die Klasse Person (inkl. Address), die wir bereits im letzten Praktikum umgesetzt haben, soll hier wieder verwendet werden. Genauer gesagt soll die Klasse Student von der Klasse Person erben und zusätzlich die folgenden Attribute und Methoden besitzen:

  • studentID: Attribut vom Typ String
  • studyProgram: Attribut vom Typ String
  • enrollmentDate: Attribut vom Typ Date. Nutzen Sie dafür bitte die bereits zur Verfügung gestellte Klasse Date (siehe Date.java)
  • Konstruktor: Konstruktur, der alle genannten und ggf. weitere, notwendige Attribute als Parameter bekommt
  • Konstruktor (ohne Parameter): Konstruktur, der keine Parameter bekommt und die Attribute mit Standardwerten initialisiert. Denken Sie daran, dafür bestehende Konstruktoren zu nutzen.
  • toString(): Methode, die alle Attribute strukturiert als String formatiert.
Hinweis: Denken Sie daran, dass bei Verwendung der Student-Klasse auch die Elternklasse Person korrekt initialisiert werden muss.

2 - Die MyTriangle-Klasse

Die in JOE integrierte Klasse Triangle kann Dreiecke initialisieren und ausgeben. Leider kann man über die bereitgestellten Konstruktoren keine Farbe übergeben und auch nicht steuern, ob das Dreieck sofort gezeichnet oder nur erstellt werden soll. Diese Einschränkungen wollen wir durch eine eigene Klasse MyTriangle als Erweiterung von Triangle beheben. Setzen Sie diese bitte um und beachten Sie dazu bitte die folgenden Anforderungen.

Anforderungen:

  • Erweiterung: MyTriangle soll Triangle erweitern.
  • Attribute: MyTriangle soll keine eigenen Attribute besitzen.
  • Farbe: Die Farbe soll direkt im Konstruktor übergeben werden können. Nutzen Sie dafür bitte die Methoden der Elternklasse.
  • Sichtbarkeit: Der Konstruktor soll außerdem ermöglichen, dass die Figur nicht automatisch gezeichnet wird. Dafür übergeben Sie bitte eine Option isVisible als Parameter.
  • Point-Objekte: Erstellen Sie bitte auch einen weiteren Konstruktor, der drei Point-Objekte als Eckpunkte (anstelle der 3 double-Koordinatenpaare von Triangle) akzeptiert. Nutzen Sie aber trotzdem die Koordinaten-Attribute von Triangle.

3 - Die Klasse PointRGB

Aufbauend auf der im Praktikum 7 entwickelten Point-Klasse sollen Sie nun eine PointRGB-Klasse entwickeln. Diese soll Point dahingehend erweitern, dass auch farbige Punkte erstellt werden können. Beachten Sie dazu die folgenden Anforderungen.

  • Attribute: Definieren Sie keine Attribute, die bereits in der Elternklassen existieren.
  • Methoden ggf. überschreiben: Überlegen Sie, ob ggf. Methoden der Elternklasse überschrieben werden müssen.
  • Farbe: PointRGB soll das Attribut Farbe erhalten. Berücksichtigen Sie das auch beim Konstruktor.
  • Initialisierung: Initialisieren Sie im Konstruktor alle Attribute. Denken Sie auch an die Elternklasse Point.
  • Objekte erstellen: Initialisieren Sie mehrere Punkte der Klassen Point und PointRGB.

4 - Komplexe Figur zeichnen

In JOE gibt es mehrere eingebaute Grafik-Klassen. Einige davon haben wir bereits kennengelernt, u.a. Dreiecke (Triangle), Rechtecke (Square) und Kreise (Circle). In dieser Aufgabe sollen Sie sich eine eigene komplexe Form überlegen, die aus mehreren Grundformen (u.a. Kreis, Dreieck, Viereck) besteht. Die Gesamtform soll mit JOE grafisch darstellt werden. Beachten Sie dazu die folgenden Anforderungen.

    Anforderungen:

  • Klasse: Definieren Sie eine Klasse für Ihre Form
  • Ursprung: Definieren Sie einen Ursprung für Ihre Gesamt-Form, z.B. den Mittelpunkt, Schwerpunkt, linke/obere Ecke - je nachdem, was für Ihre Form sinnvoll ist.
  • Anzahl Grundformen: Ihre komplexe Form besteht aus mind. 3 Grundformen, wobei mind. 2 verschiedene Formen eingesetzt werden sollen (z.B. Dreieck, Dreieck, Viereck).
  • Farbe: Die Farbe der Gesamt-Form soll konfigurierbar sein.
  • Sichtbarkeit: Ein Attribut soll den Sichtbarkeitstatus der Form speichern. Dieser soll bei der Initialsierung bereits übergeben werden. Die Form soll durch eine Funktion setVisible(boolean isVisible) sichtbar bzw. unsichtbar gemacht werden.
  • Konstrukor mit Parametern: Definieren Sie mind. einen Konstruktor, der alle Attribute initialisiert.
  • Konstrukor ohne Parameter: Definieren Sie einen Konstruktor, der keine Parameter bekommt und sorgen Sie dafür, dass trotzdem alle Attribute initialisiert werden.
  • Objekt anlegen: Legen Sie ein Objekt Ihrer Klasse in der Main.java an. Prüfen Sie das visuelle Ergebnis.
