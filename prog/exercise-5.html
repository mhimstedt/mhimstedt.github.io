Praktikum 5: Arrays

In diesem Praktikum werden wir Arrays in Java anwenden.

🚀 Lernziele

Sie können:

  • Arrays korrekt initialisieren
  • Werte von Arrays durch Wiederholungen ausgeben und verändern
  • Mehrdimensionale Arrays erstellen und zielgerichtet einsetzen.

🤔 Vorbereitung

Bitte bearbeiten Sie die folgenden Aufgaben vor Ihrem Praktikumstermin. Diese sollen sicherstellen, dass Sie die gestellten Praktikumsaufgaben inhaltlich und zeitlich schaffen.

  • Array-Initialisierung: Bitte wiederholen Sie die Möglichkeiten, Arrays in Java zu initialisieren (siehe Vorlesung 5 #8). Probieren Sie das bitte auch selbst in JOE aus.
  • Summe: Initialisieren Sie ein Array mit festen Werten. Bestimmen Sie dann mit Hilfe einer for bzw. foreach-Schleife die Summe aller Zahlen des Arrays. Schauen Sie sich hierzu auch nochmal Vorlesung 5 #16 an.

2 - Eckpunkte zeichnen

In dieser Aufgabe werden wir Eckpunkte von Vierecken zeichnen. Überlegen Sie sich dafür zunächst sinnvolle Koordinaten. Fertigen Sie ggf. eine Skizze an und lösen Sie die folgenden Teilaufgaben.

Teilaufgaben:

  • Eckpunkte als Array: Legen Sie vier Arrays p1, ..., p4 für die Eckpunkte an. Jedes Array soll dabei aus zwei double-Werten bestehen: der x- sowie y-Koordinate.
  • Eckpunkte zeichnen: Zeichnen Sie jeden der vier Eckpunkte p1, ..., p4 nun einzeln mit Hilfe von new Circle(...) und einem Radius von 5.
  • Punkte-Array: Legen Sie nun bitte ein weiteres Array punkte an. Dieses Array soll die vier Eckpunkte in einer Struktur zusammenfassen.
  • Schleife: Anstelle Circle vier Mal zu wiederholen, sollen Sie nun eine Schleife nutzen, die alle Eckpunkte des Punkte-Arrays ausgibt. Überlegen Sie, welche Schleife hierfür besonders geeignet ist.

3 - Vierecke

In dieser Aufgabe wollen wir Vierecke ohne Verwendung von Rectangle in JOE zeichnen. Dazu sollen die Eckpunkte (x- und y-Koordinaten) des Vierecks erneut als Arrays vorgegeben werden (siehe Aufgabe 2). Hier sollen Sie nun zusätzlich die Eckpunkte mit Hilfe von Linien verbinden. Initialisieren Sie dazu auch wieder ein punkte-Array, wobei die Reihenfolge der Punkte so gewählt werden soll, dass Sie diese auf einfache Art und Weise mit einer Schleife ausgeben können.

Hinweis

Sie können in JOE Linien zeichnen, indem Sie new Line(x1, y1, x2, y2) ausführen. Dabei sind (x1, y1) und (x2,y2) jeweils die x-/y-Koordinaten der Start- und Endpunkte der Linien. Alle Koordinaten sind vom Datentyp double.

Anforderungen:
  • Linien werden in einer Schleife ausgegeben.
  • Es sollen alle möglichen Vierecke funktionieren (nicht nur Rechtecke/Quadrate).
  • Es soll nur die äußere Kontur zu sehen sein. Das Viereck soll nicht (farblich) ausgefüllt werden.
  • Es sollen keine Polygone aus JOE dafür benutzt werden.

4 - Statistik über Zahlenreihe

Berechnen Sie Minimum, Maximum, Mittelwert und Spannweite (Maximum-Minimum) über eine Zahlenreihe, die in einem double-Array gespeichert ist. Initialisieren Sie dazu wieder ein Array mit festen Werten. Die berechneten Werte sollen am Ende ausgegeben werden.

Anforderungen:
  • Minimum einer Zahlreihe (Array) wird ausgegeben.
  • Maximum einer Zahlreihe (Array) wird ausgegeben.
  • Spannweite (Maximum-Minimum) einer Zahlreihe (Array) wird ausgegeben.
  • Mittelwert einer Zahlreihe (Array) wird ausgegeben. (siehe Aufgabe 1)
  • Alle Werte (Minimum usw.) werden in einer Schleife berechnet.
