Praktikum 3: Implementierung von Objektbeziehungen

In diesem Praktikum wollen wir lernen, wie Objektbeziehungen aus Klassendiagrammen in Java umgesetzt werden können.

🚀 Lernziele

Sie können:

  • Klassenbeziehungen aus Klassendiagrammen korrekt und vollständig ablesen
  • Klassenbeziehungen eines geg. Klassendiagramms in Java implementieren
  • Multiplizitäten von Klassenbeziehungen korrekt umsetzen

🤔 Vorbereitung

Bitte bearbeiten Sie die folgenden Aufgaben vor Ihrem Praktikumstermin. Diese sollen sicherstellen, dass Sie die gestellten Praktikumsaufgaben inhaltlich und zeitlich schaffen.

Aufgaben:

  • Objektbeziehungen: Bitte lesen Sie noch einmal, wofür diese gebraucht werden und wie sie genutzt werden (siehe Vorlesung 3).
  • Klasse Club: Implementieren Sie Klasse Club (engl. Verein), die als Basis für unseren Sportverein dienen soll. Anforderungen an die Implementierung können Sie dem geg. Klassendiagramm entnehmen.
  • Beziehung Club-Member: Bitte implementieren Sie die Beziehung der Klassen Club und Member, so wie es im geg. Klassendiagramm dargestellt ist.

📝 Pflichtaufgaben (1 Bonuspunkt)

Objektbeziehungen für Vereinsmodell

Im letzten Praktikum haben wir bereits mit der Implementierung eines Modells für einen Sportverein begonnen. Dieses werden wir jetzt durch weitere Klassen sowie Objektbeziehungen erweitern. Das erweiterte Modell finden Sie im folgenden Klassendiagramm. Achten Sie darauf, dass Sie Beziehungstypen und Multiplizitäten so umsetzen, wie es im Klassendiagramm dargestellt ist.

Hinweise:
  • Die Team-Klasse ist neu. Diese müssen Sie ergänzen. Achten Sie darauf, dass es im Vergleich zum vorherigen Modell einige Änderungen gibt.
  • Achten Sie unbedingt darauf, die korrekten Verbindungstypen (so wie im geg. Klassendiagramm) umzusetzen. Hierzu gibt es Beispiele in der Vorlesung 3 (#11-13).
  • Verbindungen herstellen in der Main.java: In der Main.java finden Sie ein Aufruf-Beispiel des Modells. Stellen Sie alle notwendigen Verbindungen zwischen den Klassen her.

⭐ Zusatzaufgaben (1 Bonuspunkt)

Im letzten Praktikum haben wir bereits die zusätzliche Klasse BoardMember (Vorstand) angelegt (siehe Bonusaufgabe Praktikum 2). Sollten Sie diese noch nicht umgesetzt haben, legen Sie bitte zunächst noch eine neue Klasse BoardMember entsprechend dem geg. Klassendiagramm an.

Die Klasse BoardMember soll nun zusätzlich an den Club (Verein) gebunden werden. Überlegen Sie sich, wie Sie die im geg. Klassendiagramm dargestellte Verbindung zwischen den beiden Klassen herstellen können. Schauen Sie sich ggf. auch nochmal das Vorlesungbeispiel an: Vorlesung 2 #13. Erstellen Sie bitte selbst ein einfaches Beispiel zur Demonstration der Verbindung in der Main.java.

Hinweis: Nutzen Sie insbesondere die Multiplizität aus, um es sich in der Implementierung etwas einfacher zu machen. Nehmen Sie fiktive Datumsangaben für startDate und endDate von BoardMember an.
