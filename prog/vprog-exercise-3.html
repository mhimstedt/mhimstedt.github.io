Praktikum 3: Implementierung von Objektbeziehungen

In diesem Praktikum wollen wir lernen, wie Objektbeziehungen aus Klassendiagrammen in Java umgesetzt werden können.

🚀 Lernziele

Sie können:

  • Klassenbeziehungen aus Klassendiagrammen korrekt und vollständig ablesen
  • Klassenbeziehungen eines geg. Klassendiagramms in Java implementieren
  • Multiplizitäten von Klassenbeziehungen korrekt umsetzen

🤔 Vorbereitung

Bitte bearbeiten Sie die folgenden Aufgaben vor Ihrem Praktikumstermin. Diese sollen sicherstellen, dass Sie die gestellten Praktikumsaufgaben inhaltlich und zeitlich schaffen.

Aufgaben:

  • Objektbeziehungen: Bitte lesen Sie noch einmal, wofür diese gebraucht werden und wie sie genutzt werden (siehe Vorlesung 3).
  • Klasse Club: Implementieren Sie Klasse Club (engl. Verein), die als Basis für unseren Sportverein dienen soll. Anforderungen an die Implementierung können Sie dem geg. Klassendiagramm entnehmen.
  • Beziehung Club-Member: Bitte implementieren Sie die Beziehung der Klassen Club und Member, so wie es im geg. Klassendiagramm dargestellt ist.
