Praktikum 1: Zugriffsmodifizierer

In diesem Praktikum wollen wir den Einsatz von Zugriffsmodifizierern in Java kennenlernen.

🚀 Lernziele

Sie können:

  • die Notwendigkeit von Zugriffsschutz für Attributen/Methoden bewerten
  • geeignete Zugriffsmodifizierer zielgerichtet einsetzen

🤔 Vorbereitung

Bitte bearbeiten Sie die folgenden Aufgaben vor Ihrem Praktikumstermin. Diese sollen sicherstellen, dass Sie die gestellten Praktikumsaufgaben inhaltlich und zeitlich schaffen.

Aufgaben:

  • Zugriffsmodifizierer: Bitte lesen Sie noch einmal, wofür diese gebraucht werden und wie sie genutzt werden, siehe Vorlesung #1.
  • Person-Klasse: Im GProg-Praktikum haben wir bereits die Person-Klasse (Attribute: firstname, lastname; optional: address usw.) implementiert. Bitte bringen Sie diese mit bzw. bereiten Sie diese vor.

📝 Pflichtaufgaben (1 Bonuspunkt)

1 - Person-Klasse

Ihre Implementierung der Person-Klasse (siehe Vorbereitungsaufgabe) soll nun um geeignete Zugriffsmodifizierer erweitert werden. Bearbeiten Sie dazu bitte die folgenden Teilaufgaben.

Teilaufgaben:

  • Modifizierer für Attribute : Sichern Sie die Attribute Ihrer Person-Klasse vor unbefugten (direkten) Zugriff von außerhalb der Klasse ab. Bedenken Sie dabei bitte schon, dass diese Klasse auch als Basisklasse (Elternklasse) für weitere Klassen dienen soll.
  • Getter/Setter-Methoden: Definieren Sie für die Attribute bitte geeignete get- und set-Methoden (siehe auch: Vorlesung #1:7).

2 - Student-Klasse

Wir wollen nun eine Student-Klasse implementieren. Diese soll von Person erben, um Dopplungen (bspw. Namen) zu vermeiden. Bearbeiten Sie dazu bitte die folgenden Teilaufgaben.

Teilaufgaben:
  • Student-Klasse erstellen: Erstellen Sie bitte die Klasse Student mit dem zusätzlichen Attribut id (vom Typ String). Wählen Sie einen geeigneten Zugriffsmodifizierer.
  • Konstruktoren erstellen: Erstellen Sie bitte zwei Konstruktoren - einen mit allen notwendigen Parameter für die Klasse sowie einen ohne Parameter. Bei letzterem denken Sie bitte an die Konzepte, die Sie bereits in GProg kennengelernt haben.
  • Getter-/Setter-Methoden: Erstellen Sie bitte geeignete get-/set-Methoden für das Attribut id.
  • Zugriff auf Vorname/Nachname: Kommen Sie von der Student-Klasse an den Vornamen/Nachnamen? Brauchen Sie hierfür Getter/Setter in Student? 🤔 Finden Sie es bitte heraus!

⭐ Zusatzaufgabe (1 Bonuspunkt)

3 - VisibleCircle-Klasse

Sie kennen aus GProg schon die Grafikklasse Circle. Diese zeichnet einen Kreis mit geg. Mittelpunkt und Radius, die als Parameter übergeben werden. Die Klasse bietet bereits eine set-Methode zum Setzen der x- bzw. y-Koordinaten. Leider wird dabei aber nicht überprüft, ob diese Mittelpunkt-Koordinaten auch im sichtbaren Bereich liegt. Erstellen Sie eine neue Klasse VisibleCircle, die von Circle erbt, allerdings (im Gegensatz zu Circle) prüfen soll, ob der Kreis noch vollständig im sichtbaren Bereich (siehe World) liegt. Überlegen Sie sich bitte ein Konzept, das diese Anforderung umsetzt.

Hinweis: Bedenken Sie auch, dass die Klasse VisibleCircle auch dafür sorgen soll, dass Kreise vollständig sichtbar sind, wenn bereits fehlerhafte Koordinaten bei der Ininitialisierug (Instanziierung) angegeben werden. Denken Sie auch an den Konstruktor ohne Argumente.
