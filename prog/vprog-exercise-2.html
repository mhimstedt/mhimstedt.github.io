Praktikum 2: UML-Klassendiagramme

In diesem Praktikum wollen wir den Einsatz von Klassendiagrammen in Java kennenlernen.

🚀 Lernziele

Sie können:

  • Anforderungen aus Klassendiagrammen korrekt und vollständig ablesen
  • Java-Code zu einem geg. Klassendiagramm implementieren

🤔 Vorbereitung

Bitte bearbeiten Sie die folgenden Aufgaben vor Ihrem Praktikumstermin. Diese sollen sicherstellen, dass Sie die gestellten Praktikumsaufgaben inhaltlich und zeitlich schaffen.

Aufgaben:

  • Klassendiagramme: Bitte lesen Sie noch einmal, wofür diese gebraucht werden und wie sie genutzt werden (siehe Vorlesung 2).
  • Sportverein: Überlegen Sie, welche Klassen aus Ihrer Sicht zur Modellierung von einem Sportverein notwendig sind. Notieren Sie sich diese bitte für das Praktikum.
  • Erweiterung der Person-Klasse: In der Vorlesung haben wir bereits mit der Klasse Person gearbeitet (siehe Vorlesung 2 #7-9). Bitte erweitern Sie diese vollständig und korrekt, so wie es im folgenden Klassendiagramm vorgegeben ist:
┌───────────────────────────────────────────────┐
│Person                                         │
├───────────────────────────────────────────────┤
│# firstName : String                           │
│# lastName : String                            │
│# address : String                             │
│# phone: String                                │
├───────────────────────────────────────────────┤
│+ Person(firstName : String, lastName : String,│
│  address : String, phone : String)            │
│+ Person()                                     │
│+ getFirstName() : String                      │
│+ setFirstName(firstName : String) : void      │
│+ getLastName() : String                       │
│+ setLastName(lastName : String) : void        │
│+ getAddress(): String                         │
│+ setAddress(address : String): void           │
│+ getPhone(): String                           │
│+ setPhone(phone : String): void               │
└───────────────────────────────────────────────┘

Hinweis: Bitte implementieren Sie alle Setter/Getter wie in der Vorlesung eingeführt.
