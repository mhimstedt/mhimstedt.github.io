  • Bitte stellen Sie unbedingt Aufgabe 3 (Kreise) aus dem vorhergehenen Praktikum fertig

Geben Sie bitte eine Tabelle auf Basis einer vorgegebenen Anzahl an Spalten und Zeilen aus. In jeder Tabellenzeile geben Sie bitte abwechselnd 'x' bzw. 'o' aus.

Hinweise: Mit der Funktion print() vermeiden Sie Zeilenumbrüche. Mit dem Zeichen '\n' bzw. println("") können Sie eine neue Zeile beginnen.

📝 Pflichtaufgaben

Bitte lösen Sie alle der folgenden Teilaufgaben mit JOE.

1 - Interaktives Addieren

Entwerfen Sie ein Programm, das die von Benutzer:innen über die Kommandozeile eingegebenen Werte einliest und addiert. Dabei soll als erstes nach der maximalen Summe (Maximalwert) gefragt werden. Sobald dieser Wert erreicht bzw. überschritten wurde, soll abgebrochen werden. Als Inspiration können Sie auch gern noch einmal in das Vorlesungsbeispiel schauen: Vorlesung 4 #16.

Anforderungen:

  • Die Summe wird initialisiert
  • Vorgang (Einlesen, Summieren, usw.) wird unbegrenzt wiederholt, es sei denn, die Summe ist größer/gleich dem Maximalwert (Abbruch)
  • Sollte der Maximalwert durch Addieren des neuen Wertes überschritten werden, so ist die letzte Summe (ohne den neuen Wert) auszugeben und abzubrechen.
  • Wird als neuer Wert 0 eingegeben, so soll ebenfalls abgebrochen werden.
  • Ausgabe der aktuellen Summe nach jeder Eingabe

2 - Viele Kreise

Im letzten Praktikum haben Sie mehrere Kreise entlang einer y-Koordinate gezeichnet. Das soll nun dahingend erweitert werden, dass die gesamte Zeichenfläche mit Kreisen gefüllt wird, d.h. Sie variieren nun nicht nur die x- sondern auch die y-Koordinaten der Kreismittelpunkte. Nutzen Sie bitte verschachtelte Schleifen, siehe auch Vorlesung 4 #14. Sie können den Radius gern geeignet durch Ausprobieren festlegen.

Anforderungen:

  • Kreise gehen nicht über den Bildrand
  • Kreise überlappen nicht
  • Die Zeichenfläche soll (fast) vollständig mit Kreisen gefüllt sein

3 - Kreise mit unterschiedlichen Radien

Erweitern Sie Aufgabe 2 dahingehend, dass jeder zweite Kreis größer ist als der vorhergehende. Dafür sollen Sie immer zwei verschiedene Radien abwechselnd nutzen.

Achten Sie darauf, dass die Kreise in jeder Zeile versetzt gezeichnet werden müssen (kleine über große Kreise usw.).

Anforderungen:

  • Alle Anforderungen aus Aufgabe 2
  • Zwei benachbarte Kreise in einer Zeile (x-Dimension) haben unterschiedliche Radien
  • Zwei benachbarte Kreise in einer Spalte (y-Dimension) haben unterschiedliche Radien

4 - Fortschrittsbalken

Erweitern Sie Aufgabe 1 um einen Fortschrittsbalken. Dieser soll prozentual (Maximalwert: 100%) den aktuellen Fortschritt anzeigen, z.B. bei einem Maximalwert von 120 und einem aktuellen Summenwert von 60 soll die Hälfte ausgefüllt sein.

Hierfür können Sie beispielsweise die Unicode-Zeichen ■ (\u25a0) bzw. □ (\u25a1) verwenden. Für 50 % bekommen Sie bspw. ■■■■■■■■■■□□□□□□□□□□. Dabei entspricht jedes Quadrat 5%.

Hinweis: Sie können hier bspw. 2 Schleifen nacheinander - jeweils für ■ und □ laufen lassen.

Anforderungen:

  • Alle Anforderungen aus Aufgabe 1
  • Prozentualer Fortschritt wird bestimmt und ausgegeben
  • Die Textausgabe mit dem Fortschritt aus Aufgabe 1 wird erweitert um eine grafische Ausgabe (Fortschrittsbalken)
  • Die Einheit des Fortschrittsbalken beträgt 5%, d.h. es gibt insgesamt 20 Kästchen.
