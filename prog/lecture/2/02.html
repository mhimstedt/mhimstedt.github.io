Primitive Datentypen

Ganze Zahlen

Typ Speichergröße Wertebereich
byte 8 Bit -128 bis 127

int 32 Bit ca. -2 Mrd. bis +2 Mrd.

Hinweis

int ist der Standard-Typ für ganze Zahlen.

Zeichen

Wir verwenden char für Uni-Code Zeichen:

  • Speichergröße: 2 Byte bzw. 16 Bit
  • 65536 verschiedene Zeichen
  • Jedes Zeichen hat einen Unicode-Wert, z.B. ‘A’: 65

char buchstabeGross = 'A';

char buchstabeKlein = 'a';

char symbol = '♬';

Wahrheitswerte

  • Boolesche Werte sind Datentypen mit zwei möglichen Werten: true und false
  • In Java heißt dieser Datentyp boolean



Variablen

Variablen sind Container (Platzhalter) für typisierte Inhalte

Variablen

Diese Inhalte können sein:

  • Zeichen wie a, b, c
  • Zeichenketten wie “Programmieren ist cool”
  • Ganze Zahlen wie 1, 2, …, 1’000’000
  • Gleitkommazahlen wie 1.23, 1e3 und 1e-2
  • Wahrheitswerte: true und false

Namen für Variablen

Konventionen:

  • Variablennamen sollten beschreibend sein
  • Verwende camelCase
  • Beginne mit einem Buchstaben
  • Groß-/Kleinschreibung: myint und myInt sind unterschiedliche Bezeichner
  • Keine reservierten Wörter verwenden (u.a. class, int)
  • Kurze, prägnante Namen sind besser als kryptische Abkürzungen

Beispiele

int 1value

int $id

boolean class

double VAL

int userAge

double accountBalance

String id2name[]

Weitere Tipps

  • Wähle sprechende Namen: price statt p, counter statt c
  • Konstante Werte in ALL_CAPS: z.B. V_X, V_Y
  • Vermeide Abkürzungen, außer sie sind allgemein bekannt (id, url)

Initialisierung vs. Zuweisung

Hinweis

Wird eine Variable definiert, so kann man diese optional mit einem Wert initialisieren. Das ist auch grundsätzlich zu empfehlen, damit die Variable einen definierten (initialen) Wert erhält. Dieser Wert lässt sich in der Regel auch später durch eine Zuweisung noch überschreiben.

Bei komplexen (nicht primitiven) Datentypen wird der Unterschied zwischen Zuweisung und Initialisierung später noch eine große Rolle spielen.

Beispiel:

int a = 1;

→ a wird hier mit Wert 1 initialisiert

int a;

a = 1;

→ a wird hier nicht initialisiert; der Wert 1 wird aber später zugewiesen.

Zuweisung vs. Vergleich

Eine Zuweisung = ist nicht das Gleiche wie ein Vergleich ==

Beispiel:

a == b → liefert true/false

a = b → Variable a wird mit Wert von b überschrieben
