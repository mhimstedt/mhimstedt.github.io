Was ist ein Array?

  • Ein Array ist eine Datenstruktur, die mehrere Elemente vom gleichen Datentyp zusammenhängend speichern kann.
  • Der Zugriff auf einzelne Elemente erfolgt über einen Index
    • z.B. array[0] für das 1. Element

Eigenschaften von Arrays

  • Feste Größe: Anzahl der Elemente nach Initialisierung nicht mehr veränderbar
  • Wahlfreier Zugriff: Die Zugriffszeit auf Elemente ist konstant, egal auf welches zugegriffen wird
  • Typenbindung: Alle Elemente müssen von demselben Datentypen sein

Arrays in Java


Datentyp[] arrayName = { Element1, Element2, …};



Datentyp[] arrayName = new Datentyp[Größe];

Beispiele

Deklaration eines int-Arrays:

int[] ganzeZahlen = {1, 3, 5, 8};

Deklaration eines double-Arrays:

double[] gleitkommaZahlen = {0.12, 1., -2.54, 9.1};

Arrays … auch mit Strings möglich:

String[] woerter = {"Programmieren", "ist", "cool", "."};

Zugriff, Indizes und Größe

Der Zugriff auf Elemente erfolgt mittels []-Operator:

int[] zahlen = {1, 3, 4, 5, 9} 
zahlen[0] = 10;      // 1. Element überschreiben
int x = zahlen[0];   // 1. (neues) Element lesen


Die Länge eines Arrays kann man mit length abfragen, z.B.

int[] zahlen = {1, 3, 4, 5, 9} 

println("Anzahl Elemente:" + zahlen.length);

Initialisierung

  1. Leeres Array mit gegebener Länge:
int[] leeresArray = new int[5]; // alle Werte default 0
  1. Feste Werte bei Deklaration:
int[] statischeWerte = {1, 2, 3, 4, 5};
  1. Werte zur Laufzeit zuweisen:
int[] dynamischeWerte = new int[5];
for (int i = 0; i < dynamischeWerte.length; i++) {
  dynamischeWerte[i] = i * 2; // z. B. Werte verdoppeln
}

Mehrdimensionale Arrays

Datentyp[][] name = {

   { Element11, Element12, …},

   { Element21, Element22, …}

};

Datentyp[][] name = new Datentyp[Größe 1][Größe 2];

Eigenschaften

  • In Java sind mehrdimensionale Arrays: »Arrays von Arrays«
  • Auch hier gilt: der Datentyp ist für alle Elemente gleich
  • Der Zugriff erfolgt über [][]
    • Bei 2D: erst Zeile, dann Spalte
  • Beispiel: ein 2D-Array int[][] ist ein Array, dessen Elemente wiederum int[] sind.

Beispiele

Eine Tabelle können wir in Java mit einem 2D-Array abbilden, z.B.:

// Rechteckiges 2D-Array (z. B. 4 Zeilen, 5 Spalten)
int[][] matrix = new int[4][5];

// Zugriff: matrix[zeile][spalte]
matrix[0][0] = 1;  // 1. Zeile, 1. Spalte
matrix[2][3] = 1;  // 3. Zeile, 4. Spalte

Beispiele: Bilder

⚠️ Bildkoordinatensystem: y-Achse ist gespiegelt

Ein Graustufen-Bild mit 1280x720 Pixeln:

float[][] bildGrau = new float[720][1280];

bildGrau[100][200] = 0.78f;  // Achtung: x: 200, y: 100

Ein Farb-Bild (RGB) mit 1280x720 Pixeln:

int[][][] bildRGB = new int[720][1280][3]; // (3 Werte/Pixel)

// Setze Pixel an (200,100) auf Rot (255,0,0)
bildRGB[100][200][0] = 255;  // Rot-Wert
bildRGB[100][200][1] = 0;    // Grün-Wert
bildRGB[100][200][2] = 0;    // Blau-Wert

mit Schleifen

for-Schleife für Arrays

Wir können length nutzen, um eine Abbruch-Bedingung festzulegen:

int[] werte = {10, 20, 30, 40};
for (int i = 0; i < werte.length; i++) {
  println("Index " + i + ": " + werte[i]);
}

Für mehrdimensionale Arrays funktioniert das auch:

int[][] tabelle = { { 1, 2 }, { 3, 4 } };
for (int i = 0; i < tabelle[0].length; i++) {
  for (int j = 0; j < tabelle[1].length; j++) {
    print(tabelle[i][j] + " ");
  }
  println();
}

»for each«

for (Datentyp item : container)   {

   Anweisung;

}


item und Elemente von container müssen vom gleichen Datentyp sein.

»for each«-Schleife

  • Kurzschreibweise zum Durchlaufen eines Arrays ohne Index-Nutzung → Zugriff erfolgt direkt auf das Element
int[] zahlen = {1, 2, 3, 4};

for (int wert : zahlen) {
  println("Wert: " + wert);
}

 

// Zeichnen der Eckpunkte eines Dreiecks
double[][] punkte = { {200., 100. }, {100., 200.}, {300., 200.}};

for (double[] punkt : punkte) {
  new Circle(punkt[0], punkt[1], 5.);
}

»for each«-Schleife

 

⨁ Vorteile:

  • Kompakter und weniger fehleranfällig bei Indexfehlern
    • z.B. Start/Ende bei for-Schleife und < bzw. <=

⊖ Nachteile:

  • Kein Index: wenn man Index braucht, muss man:
    • eine klassische for-Schleife nutzen bzw.
    • selbst einen Zähler (i++) zusätzlich implementieren

✅ Zusammenfassung

  • Elemente vom gleichen Datentyp im Array zusammenfassen
    • z.B. Datenreihen, Ergebniswerte
  • Wir können Arrays verschachteln für mehrdimensionale Daten
    • z.B. Koordinaten von geometrischen Formen
  • foreach-Schleifen: kompakter & weniger fehleranfällig (für Arrays)
