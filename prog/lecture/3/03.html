Kontrollstrukturen

Was sind Kontrollstrukturen?

  • Normalerweise laufen Anweisungen nacheinander ab
  • Mit Kontrollstukturen kann der Ablauf eines Programms gezielt gesteuert werden

Wozu werden Kontrollstrukturen genutzt?

Sie werden eingesetzt, um:

  • Code-Bereiche abzugrenzen

    ➔ Block

  • Entscheidungen zu treffen

    ➔ Verzweigung

  • Wiederholungen auszuführen

    ➔ Schleife

  • den Programmfluss zu steuern

    ➔ Sprung

Blöcke

Wofür werden Blöcke genutzt?

  • Programm-Code kann damit strukturiert werden
  • Der Gültigkeitsbereich von Variablen wird begrenzt
  • Viele Kontrollstrukturen nutzen Blöcke

int a = 2;

{

   int a = 3;

   println(a);      // Ausgabe: 3

}

println(a);      // Ausgabe: 2

Operatoren und Ausdrücke

Operatoren und Ausdrücke

  • Operatoren bilden Ausdrücke
  • Ausdruck = Operanden + Operator
  • Ergebnis ist ein Wahrheitswert

Arten von Operatoren

  

Kategorie Operatoren Beispiel
Arithmetisch +, -, *, /, % a + b
Vergleich ==, !=, <, >, <=, >= a > b
Logisch &&, ||, ! a && b
Zuweisung =, +=, -=, *=, /= a += 2
Inkrement/Dekrement ++, – a++

Beispiel-Ausdrücke

  

int a = 5;
int b = 3;
int summe = a + b;    // arithmetischer Ausdruck
boolean vergleich = a > b; // Vergleichsausdruck

  

boolean a = true;
boolean b = false;

boolean und = a && b; // false
boolean oder = a || b; // true
boolean nicht = !a;    // false

Verzweigungen

if-Anweisung

Wenn …, dann …

if-Anweisung

  • Führt Code aus, wenn Bedingung wahr ist
  • Keine Alternative nötig
  • Wird oft für einfache Prüfungen verwendet
int zahl = 10;

if (zahl > 5) {
  println("Zahl ist größer als 5");
}

if-else-Anweisung

  • Dienen zur Entscheidung im Programmablauf
  • Bedingungen werden mit Vergleichs- oder logischen Operatoren geprüft
  • if: führt Block aus, wenn Bedingung wahr ist
  • else: führt Block aus, wenn Bedingung falsch ist
int zahl = 5;

if (zahl > 0) {
  println("Positive Zahl.");
} else {
  println("Zahl ist nicht positiv.");
}

Go harder: if, else if & else

if (Ausdruck) {

   Anweisung;

} else if (Ausdruck) {

   Anweisung;

} else {

   Anweisung;

}

switch-Anweisung

  • if-else-Kontruktionen werden schnell unübersichtlich ➔ Hier kann eine switch-Anweisung Abhilfe schaffen

  • Idee: Variable / Ausdruck mit mehreren bekannten Vergleichswerten überprüfen

  • Beispiel: Pfeiltasten beim Jump’n Run Spiel

switch (Ausdruck) {

   case Option: Anweisung; break;

   …

   default : break;

}

Schleifen

  • dienen dazu, Anweisungen zu wiederholen
    • z.B. bestimmte Aktionen wie Ausgaben
  • zum Auslesen aller Informationen einer Datenstruktur (z.B. Liste)
  • Automatisierung von Aufgaben, ohne Code mehrfach zu schreiben

while-Schleife

  • prüft Bedingungen am Kopf der Schleife (vor Wiederholung)
    • wiederhole Anweisungen solange wie Bedingung erfüllt ist

 

while (Bedingung) {

  Anweisung;

}

while-Schleife in JOE

do-while-Schleife

  • prüft Bedingungen am Ende der Schleife (nach Wiederholung)
    • auch hier: wiederhole Anweisungen solange wie Bedingung erfüllt ist

  

do {

  Anweisung;

} while (Bedingung);

do-while-Schleife in JOE

for-Schleife

  • ermöglicht eine festgelegte Anzahl von Wiederholungen
    • auch Zählschleife genannt

for (Datentyp Zähler = Startwert; Zähler < Endwert; Zähler += 1) {

  Anweisung;

}
