Praktikum 8: Klassen und Objekte II

In diesem Praktikum werden wir Klassen und Objekte weiter in Java einsetzen und praktisch anwenden.

🚀 Lernziele

Sie können:

  • Klassen für typische Aufgaben anwenden

🤔 Vorbereitung

Bitte bearbeiten Sie die folgenden Aufgaben vor Ihrem Praktikumstermin. Diese sollen sicherstellen, dass Sie die gestellten Praktikumsaufgaben inhaltlich und zeitlich schaffen.

Definieren Sie eine Klasse Person, die über die folgenden Attribute und Methoden verfügen soll:

  • firstname: Attribut
  • lastname: Attribut
  • street: Attribut
  • zipcode: Attribut
  • location: Attribut
  • Person: Konstruktur, der alle genannten Attribute als Parameter bekommt

Bringen Sie bitte unbedingt eine digitale Lösung ihrer Vorbereitung mit, damit Sie im Praktikum daran weiter arbeiten können.

📝 Pflichtaufgaben

Bitte lösen Sie alle der folgenden Teilaufgaben mit JOE.

1 - Die Person-Klasse

In der Vorbereitungsaufgabe haben Sie bereits die Person-Klasse angelegt. Wir werden diese nun weiter ausbauen und praktisch einsetzen.

Teilaufgaben:

  • Weiterer Konstruktor: Legen Sie einen weiteren Konstruktor an, der nur firstname, lastname übergeben bekommt.
  • Konstruktoren vereinfachen: Vermeiden Sie Code-Duplikate in Ihren Konstruktoren, indem diese sich gegenseitig aufrufen (siehe auch Vorlesung 8 #21).
  • Methode output: Legen Sie eine Methode output() an, die alle Attribute strukturiert ausgeben soll.
  • Address-Klasse definieren: Definieren Sie eine weitere Klasse Address, die Attribute street, zipcode und location enthalten soll.
  • Address-Klasse einsetzen: Ersetzen Sie die Attribute street, zipcode und location in der Klasse Person durch die neue Address-Klasse.
  • Anpassungen für Address: Passen Sie alle Konstruktoren und Methoden in Person dahingehend an, dass Sie korrekt mit der neuen Address-Klasse funktionieren.
  • Person-Objekte anlegen: Legen Sie in der Main.java eine Person testweise an und lassen Sie sich die Daten mit der klasseneigenen output-Methode ausgeben.

⭐ Zusatzaufgaben

Hinweis: Für den Bonuspunkt reicht es, eine der folgenden Aufgaben zu lösen.

2 - Palindrome erkennen

Ein Palindrom ist ein Wort, das vorwärts wie rückwärts gleich gelesen wird, z.B. Otto, Ebbe, Hannah.

Aufgabe: Schreiben Sie eine Funktion palindrom(), die als Parameter einen String übergeben bekommt. Für diesen String soll überprüft werden, ob es sich um ein Palindrom handelt. Die Funktion soll true/false (boolean) zurückgeben, je nachdem ob ein Palindrom vorliegt oder nicht.

3 - Stern-Klasse

Im Praktikum 2 haben wir uns in Aufgabe 5 (Zusatz) mit der Darstellung von Sternen beschäftigt. Passen Sie diese Implementierung hinsichtlich folgender Anforderungen an:

    Anforderungen:

  • Darstellung exakt wie in Aufgabe 5 (Praktikum 5)
  • Stern-Klasse: Legen Sie eine Stern-Klasse an, die zwei (gleichseitige) Dreiecke als Attribute hat.
  • Konstruktor: Die Stern-Klasse soll einen Konstruktor erhalten, der lediglich den Mittelpunkt des Sterns erhält.
  • Ausgabe: Instanziieren Sie mehrere Stern-Objekte mit unterschiedlichen Mittelpunkten und geben Sie diese grafisch aus.
