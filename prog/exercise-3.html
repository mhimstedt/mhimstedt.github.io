Praktikum 3: Kontrollstrukturen I

In diesem Praktikum werden wir die in der Vorlesung eingeführten Kontrollstrukturen praktisch anwenden.

Lernziele

Sie können:

  • komplexe Verzweigungen umsetzen
  • einfache Problemstellungen mit Wiederholungen implementieren
  • weitere geometrische Figuren in JOE zeichnen (u.a. Kreise)

Vorbereitung

Bitte bearbeiten Sie die folgenden Aufgaben vor Ihrem Praktikumstermin. Diese sollen sicherstellen, dass Sie die gestellten Praktikumsaufgaben inhaltlich und zeitlich schaffen.

  • Verzweigungen: Verinnerlichen Sie sich bitte nochmal, welche Möglichkeiten der Verzweigungen es in Java gibt, siehe Vorlesung 3
  • Wiederholungen/Schleifen: Verinnerlichen Sie sich bitte nochmal, welche Möglichkeiten der Wiederholungen bzw. Schleifen es in Java gibt, siehe Vorlesung 3
  • Zahlenprüfung: Benutzer:innen sollen über die Kommandozeile in JOE eine Zahl eingeben. Ihr Programm soll prüfen, ob es sich dabei um eine positive oder negative Zahl handelt. Im Falle einer 0 soll es "Weder positiv noch negativ" ausgeben.
  • Zahlenausgabe: In dem zweiten Codefenster ist ein Programm gegeben, dass die Zahlen von 1 bis 10 ausgeben soll. Bitte prüfen Sie es auf Korrektheit und beheben ggf. auftretende Fehler.


Pflichtaufgaben

Bitte löse die folgenden Aufgaben mit JOE.

1 - Konzerttickets

Für ein Konzert sollen Tickets gestaffelt in drei verschiedenen Preis-Kategorien zu 45,50 € / 35,00 / 25,50 € verkauft werden. Zusätzlich soll erfragt werden, ob Kaufinteressierte Anspruch auf Ermäßigung (50%) bzw. freien Eintritt für Kinder unter 3 Jahren haben.

Schritte:

  • Variablen: Legen Sie geeignete Variablen für die Preise der Kategorien an. Legen Sie auch geeignete Variablen zur Kategorieauswahl sowie zur Erfassung des Ermäßigungsanspruchs bzw. Kindertarifs an. Initialisieren Sie alle Variablen.
  • Preiskategorie: Nutzen Sie Verzweigungen (if / else bzw. switch), um den Ticketpreis auf Basis der Kategorie zu bestimmen.
  • Ermäßigung / Kindertarif: Prüfen Sie zusätzlich, ob Kaufinteressierte Anspruch auf Ermäßigung bzw. den Kindertarif haben. Wenn ja, korrigieren Sie den Preis bitte entsprechend.
  • Eingabe: Wenn Sie alle vorherigen Schritte abgeschlossen haben und Ihre Preisermittlung stimmt, erfragen Sie bitte Preiskategorie, Ermäßigungsanspruch/Kindertarif über die Kommandozeile. Geben Sie den Kaufinteressierten bitte auch eine Übersicht der Preise in den Kategorien und der möglichen Ermäßigungen.

2 - Zahlen raten

Wir programmieren nun ein kleines Zahlenratespiel. Dabei sollen Benutzer:innen die Möglichkeit haben, mehrmals Zahlen über die Kommandozeile einzugeben. Wenn die eingegebene Zahl stimmt, wird den Benutzer:innen gratuliert.

Zufallszahlen

Hinweis: Zufallszahlen können Sie in JOE mithilfe von Math.random() erzeugen. Damit erhalten Sie eine Gleitkomma-Zahl im Intervall [0;1]. Wenn Sie eine Zahl bspw. im Intervall [0;10] möchten, rechnen Sie einfach Math.random()*10. Die Zufallszahlen sind vom Datentyp double. Wenden Sie die Funktion Math.round() an, um diese auf die nächste ganze Zahl zu runden: int zufallsZahl = Math.round(Math.random()*10.)

Schritte:

  • Variablen: Legen Sie Variablen für die zu ratende Zahl sowie die einzugebene Zahl fest. Initialisieren Sie beide Zahlen zunächst mit festen Werten.
  • Vergleich: Prüfen Sie mithilfe einer Abfrage (if), ob die eingebene Zahl (hier noch von Ihnen festgelegt) mit der zu ratenden Zahl übereinstimmt.
  • Eingabe: Lesen Sie die Benutzereingabe nun mittels Input ein und vergleichen Sie diese mit der Ratezahl.
  • Wiederholung: Erweitern Sie Ihr Programm nun durch eine Schleife. Dadurch soll der Benutzer mehrmals nach einer Zahl gefragt werden, bis eine maximale Anzahl erreicht ist. Die Maximalzahl legen Sie bitte mithilfe einer Variable fest.
  • Zufallszahl: Legen Sie nun mithilfe der Funktion Math.random() eine zufällige Ratezahl fest. Lesen Sie dazu bitte genau den obigen Hinweis zu Zufallszahlen. Geben Sie nach Erreichen der maximalen Versuche die Ratezahl bitte aus.

3 - Kreise zeichnen

In dieser Aufgabe zeichnen wir mehrere Kreise nebeneinander.

Kreise in JOE

Hinweis: Kreise können Sie in JOE mithilfe von new Circle(mx, my, r) erzeugen, wobei (mx, my) die Mittelpunktkoordinaten und r der Radius des gewünschten Kreises sind: z.B. new Circle(200., 200., 50) erzeugt einen Kreis mit dem Mittelpunkt (200.,200.) und einem Radius von 50 [Pixel].

Schritte:

  • Kreise in JOE: Zeichnen Sie einen Kreis mithilfe von new Circle() im Ausgabefenster. Lesen Sie den obigen Hinweis dazu bitte genau. Achten Sie darauf, dass der Kreis vollständig sichtbar ist. Die Zeichenfläche beträgt initial 800x600 Pixel.
  • Wiederholung: Mithilfe einer Schleife sollen nun mehrere Kreise nebeneinander gezeichnet werden. Variieren Sie dazu die entsprechenden Mittelpunktkoordinaten der Kreise. Probieren Sie zunächst geeignete Radien und Abstände für die Kreise aus, sodass sich diese nicht überlappen und nicht über die Zeichenfläche hinaus gegangen wird (vollständige Kreise).

    • Zusatzaufgaben (max. 1 Punkt)

    4 - Dynamische Radien und Abstände für Kreise

    Benutzer:innen sollen nun eine Anzahl von gewünschten Kreisen eingeben. Berechnen Sie, wie groß Radien und Abstände für die gewünschte Anzahl von Kreisen sein müssen und prüfen Sie, ob dies auch möglich/sinnvoll ist. Wenn ja, zeichnen Sie bitte die gewünschte Anzahl Kreise. Gehen Sie von einer Zeichenfläche von 800x600 Pixel aus (bitte als Variablen definieren).

    5 - Länder und Hauptstädte

    Benutzer:innen sollen die Namen von Hauptstädten für festgelegte Länder eingeben. Dabei soll den Benutzer:innen zunächst eine nummerierte Liste mit Ländern angezeigt werden. Daraufhin sollen diese sich zunächst für ein Land entscheiden, indem Sie die Zahl des Listenelements eingeben. Sie sollen dann nach der Hauptstadt gefragt werden. Gratulieren Sie ihnen, wenn es richtig ist und ermutigen Sie sie zum erneuten Versuch, wenn es nicht stimmt. Wiederholen Sie die Abfrage unendlich (Benutzer:innen schließen das Programm selbst).

    Hinweis: Nutzen Sie gern auch die Funktion toLowerCase() für Strings. Damit können Sie auf einfache Art und Weise auch "madrid" statt "Madrid" als korrekt anerkennen. Ein Beispiel dafür ist im Programm-Code unten gegeben.
