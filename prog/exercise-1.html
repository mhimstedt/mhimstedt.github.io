Praktikum 1: Einstieg in die Java Online IDE

In diesem Praktikum lernen Sie die Java Online IDE (kurz: JOE) kennen und wenden erste Programmierkenntnisse aus der Vorlesung an.

Lernziele

Sie können:

  • sicher und zielführend mit der IDE umgehen
  • Zeichenketten auf der Konsole ausgeben
  • berichten, was mit JOE alles möglich ist

Vorbereitung

Bei diesem Praktikum ist noch keine Vorbereitung notwendig. Damit starten wir ab dem nächsten Termin.

Aufgaben

Bitte lösen Sie die folgenden Teilaufgaben mit JOE.

Teil 1 - IDE-Nutzung

Start Führen Sie den gegebenen Code aus, indem Sie auf klicken oder durch Drücken von F5 (das IDE-Fenster muss dafür aktiv sein, d.h. Sie müssen darauf klicken).

Vollbild Für das längere Arbeiten am Code empfiehlt sich der Vollbildmodus. Diesen können Sie durch Klicken von starten und später durch Drücken von ESC wieder verlassen. Probieren Sie das bitte nun selbst.

Schrittmodus Normalerweise wird immer Ihr vollständiges Programm ausgeführt. Sollten Sie das einmal nicht wollen, können Sie stattdessen auch schrittweise vorgehen. Dazu klicken Sie bitte das Icon neben Run . Erweitern Sie Ihren Programm-Code um weitere Zeilen (z.B. mehrere print()-Ausgaben) und gehen Sie schrittweise durch den Programm-Code. Die weiteren Icons/Funktionalitäten daneben werden Sie zu einem späteren Zeitpunkt genauer betrachten.

Speichern Ihr Programm-Code wird auf Ihrem Rechner im Browser gespeichert (genauer gesagt in einer IndexedDB), d.h. dass diese auch nach einem Rechner-/Browser-Neustart in der Regel noch verfügbar sind. Sicherheitshalber sollten Sie aber auch regelmäßig ihren aktuellen Stand zwischenspeichern, insbesondere, wenn der Code komplexer wird. Das können Sie durch Klicken des Icon erreichen. Die Dateien bekommen die Dateierweiterung *.json. Speichern Sie Ihren aktuellen Programm-Code bitte einmal auf Ihrer Festplatte.

Laden Den gespeicherten Code will man natürlich auch gern wieder laden. Dazu können Sie Dateien, die mit JOE (json) gespeichert wurden, durch Klicken des Icon öffnen. Laden Sie den eben gespeicherten Programm-Code bitte einmal von Ihrer Festplatte. Wenn Sie den Code vorher aus JOE entfernen (oder verändern), können Sie prüfen, dass wirklich der Code von der Festplatte geladen wird. Achtung: Sie können hier keine Textdateien, *.java-Dateien o.ä. laden.

Zurücksetzen Mit der Schaltfläche Code Reset können Sie Ihr Programm-Code (aus Ihrer Browser-Datenbank, siehe oben) löschen. Beachten Sie bitte, dass er dann aber nur durch das Laden von einer Datei wiederhergestellt werden kann. Testen Sie das Feature auch gern mal.

Hinweis

Tipp: Wenn Sie keinen gültigen Programm-Code haben, d.h. bspw. Syntaxfehler oder leere Quelldateien, wird das Symbol nicht angezeigt. Erst, wenn Sie die Fehler korrigiert haben, lässt sich das Programm wieder ausführen.

Aber: Das heißt wiederum nicht, dass ihr Programm korrekt läuft, nur, weil Sie es starten können. Im Laufe des Kurses werden wir noch weitere Fehlerquellen kennenlernen, die nicht vorab erkennbar sind.

Teil 2 - Erste Schritte

In der folgenden Teilaufgabe wollen wir den Namen von Benutzer:innen über die Konsole einlesen, um diese persönlich zu begrüßen.

Hinweis

Das Einlesen von der Konsole können Sie mit Hilfe von Input.readString("") realisieren. Mit println() können Sie etwas ausgeben. Durch Verschachteln dieser beiden Funktionen können Sie - ohne Zwischenspeicherung - eingelesene Werte direkt wieder ausgeben, z.B. println(Input.readString()). Außerdem können Sie auch Zeichenketten mit dem +-Operator verbinden (siehe folgendes Bsp.).

Frage Fragen Sie den/die Benutzer:in nach dem Vornamen: Bitte geben Sie Ihren Vornamen ein:

Einlesen Lesen Sie bitte nun den Vornamen ein.

Ausgabe Geben Sie zunächst durch Verschachteln von println() und Input.readString() den Namen direkt wieder aus.

Begrüßung Passen Sie den Code nun bitte so an, dass der/die Benutzer:in persönlich begrüßt wird: Hallo ...! Willkommen bei GProg!

Teil 3 - Inspiration und Motivation

Die folgenden Programme sollen Ihnen ein Gefühl geben, was wir mit JOE und Java alles machen können. Starten Sie bitte die Programme und spielen Sie gern etwas damit herum. Ich hoffe, dass diese Beispiele motivieren, das Programmieren zu lernen. Keine Sorge: Sie müssen den Programm-Code noch nicht verstehen. Dafür haben wir jetzt die nächsten beiden Semester Zeit. Viel Spaß!

JOE kann eine Vielzahl von 2D-Grafiken, wie bspw. Dreiecke, Vierecke, Kreise und Polygone anzeigen. Neben verschiedenen Farben und Rändern lassen sich bspw. auch Alpha-Kanäle einstellen, um halbdurchlässige Objekte zu erzeugen.

Das nächste Beispiel zeigt Ihnen das Spiel Pong. Um es zu starten, öffnen Sie bitte die Datei Pong.java und klicken Sie auf das Run-Symbol. Durch Drücken der Leertaste startet das Spiel. Sie können die Schläger mit Hilfe der Cursortasten (hoch/runter) sowie Q und A steuern. Beachten Sie bitte, dass die Menüleiste sich nun unten befindet.

Auf der Webseite des Entwicklers der Java Online-IDE, Martin Pabst, finden Sie noch viele weitere Beispiele, u.a. auch für 3D-Grafiken: https://www.learnj.de/. Von dort stammen auch die obigen Beispiele.
