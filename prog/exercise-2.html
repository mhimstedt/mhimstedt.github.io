Praktikum 2: Variablen und Datentypen

In diesem Praktikum werden wir Variablen und Datentypen in Java praktisch anwenden. Außerdem werden wir erste geometrische Figuren in JOE kennenlernen.

Lernziele

Sie können:

  • Variablen anlegen
  • sicher mit unterschiedlichen Datentypen arbeiten
  • passende Unicode-Zeichen finden und zielgerichtet einsetzen
  • erste Berechnungen durchführen
  • geometrische Primitive mit JOE ausgeben

2 - Kontakte erfassen und ausgeben

In dieser Aufgabe sollen Kontaktdaten erfasst und ansprechend ausgegeben werden. Dabei sollen die folgenden Informationen enthalten sein: Vorname, Nachname, Adresse, Telefonnummer, E-Mail-Adresse.

Hinweis

Tipp: Sie können Unicode-Zeichen auf verschiedene Art und Weise anzeigen. Eine Möglichkeit ist die direkte Darstellung in der Ausgabe, z.B. println("\u265f"). Alternativ kann man ein Unicode-Zeichen als hexadezimale Zahl interpretieren und explizit als char casten, z.B. char uniCode = (char) 0x265F.

Schritte:

  • Variablen: Legen Sie Variablen vom Typ String für alle o.g. Kontaktinformationen an.
  • Daten-Eingabe: Lesen Sie die Informationen nun nacheinander mittels Input ein und speichern Sie diese auf den zuvor angelegten Variablen ab.
  • Strukturierte Ausgabe: Stellen Sie mit Hilfe von println nun die eingebenen Kontaktinformationen stukturiert zeilenweise dar.
  • Symbole: Ergänzen Sie Ihre Ausgabe nun durch Symbole (Telefon, Adresse, E-Mail). Nutzen Sie dafür bitte geeignete Unicode-Zeichen.

3 - Rechtecke zeichnen

In dieser Aufgabe sollen zweidimensionale Rechtecke gezeichnet werden. Dazu sollen zunächst die notwendigen Parameter abgefragt werden.

Hinweis

Tipp: Wir verwenden in JOE ein Bild-Koordinatensystem (2D), dessen Koordinatenursprung in der linken, oberen Ecke liegt. Je weiter rechts ein Objekt liegt, desto größer ist die x-Koordinate. Je weiter unten ein Objekt liegt, desto größer ist die y-Koordinate (siehe Abbildung). Top und left wird als Ursprung des Rechtecks (ebenfalls linke, obere Ecke) angegeben.

Schritte:

  • Rechteck-Parameter: Legen Sie vier Variablen vom Typ double an, die den Ursprung eines Rechtecks sowie die Höhe und Breite erfassen. Initialisieren diese zunächst mit sinnvollen Werten.
  • Zeichnen: Mit Hilfe von new Rectangle(x,y,width,height) können Sie dieses Rechteck nun zeichnen. Variieren Sie die Koordinaten und Größe des Rechtecks, um ein Gefühl für die grafische Darstellung in JOE zu bekommen.
  • Interaktive Eingabe: Lesen Sie von der Kommandozeile mit Hilfe von Input jeden Parameter einzeln ein. Achten Sie dabei darauf, die eingegebenen Informationen korrekt einzulesen bzw. so zu konvertieren, dass Sie auch korrekt Ihren Variablen zugewiesen werden können.

4 - Dreiecke zeichnen

In dieser Aufgabe sollen zweidimensionale Dreicke gezeichnet werden. Hierzu verwenden wir den Typ Triangle in JOE. Dieser erwartet die Koordinaten der Eckpunkte als Parameter. Wir wollen allerdings die Benutzer:innen nur zur Eingabe des Schwerpunkts (Ursprung) sowie einer Seitenlänge auffordern (gleichseitiges Dreieck). Die beiden fehlenden Eckpunkte sollen dann bestimmt werden.

Hinweis

Tipp: Für die Erstellung von Dreiecken in JOE müssen wir die drei Eckpunkte (x1,y1), (x2,y2), (x3,y3) eingeben. Die Reihenfolge ist in der folgenden Abbildung illustriert.

Schritte:

  • Eckpunkte festlegen: Überlegen Sie sich zunächst geeignete Koordinaten für Eckpunkte eines Dreiecks. Legen Sie hierfür bitte geeignete Variablen an.
  • Zeichnen: Zeichnen Sie das zuvor festgelegte Dreieck (siehe Variablen) mittels new Triangle(x1,y1,x2,y2,x3,y3). Erzeugen Sie bitte verschiedene Dreiecke und prüfen Sie das Ergebnis visuell.
  • Eckpunkte bestimmen: Nun sollen Sie Ihre Anwendung dahingehend erweitern, dass nur der Schwerpunkt sowie die Seitenlänge eines gleichseitigen Dreiecks eingegeben werden. Die verbleibenden Eckpunkte sollen berechnet und die resultierenden Koordinaten dann auf den Eckpunkt-Variablen gespeichert werden. Testen Sie Ihr Programm.
  • Interaktive Eingabe: Fragen Sie die beiden Parameter nun mittels Input von der Kommandozeile ab. Es sollen dann ein Dreieck auf Basis der eingelesenen Werte erzeugt werden.
